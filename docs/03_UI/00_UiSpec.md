# UI 视觉规范

> 来源：总规格书第八章。视觉方向：暗色奇幻故事书 + 纸张卡牌 + 简约休闲。参考的是氛围与设计理念，不复制任何现有游戏的布局或专属视觉资产。
>
> 个人开发无专职美术：基础素材来自 itch.io 免费资源（许可证审计见 04_Platform/00_Compliance.md 第 4 节），"自己的视觉"通过**统一设计变量 + 二次加工 + 统一卡牌模板**实现（见第 8 节），不违反本原则。

## 2. 字体规范

三级层级（数值为设计稿基准，美术启动时冻结）：

| 层级 | 用途 | 基准字号 |
|---|---|---|
| 一级 | 关卡标题、关键结果 | 32 |
| 二级 | 卡牌名称、面板标题 | 24 |
| 三级 | 说明、数值、辅助提示 | 16（最小不低于 14，适配小屏时等比缩放） |

- 字号层级固定，重要信息对比度足够。
- 数字与文字不用过度装饰字体。
- 重要信息不能只靠颜色区分（兼顾色弱）。
- 字体必须可商用授权（游戏内通过云端字体注册下发，主域同步字体族给子域用于排行榜渲染）。

## 3. 卡牌视觉规范

所有卡牌使用统一组件，结构包含：

1. 卡牌外框。
2. 卡牌类型标识。
3. 卡牌名称。
4. 插画或图形区域。
5. 主要数值。
6. 效果说明。
7. 稀有度装饰。
8. 状态覆盖层。

不同卡牌可用不同纹理与图形，但不得改变基础信息层级。

### 卡牌状态（必须统一）

| 状态 | 说明 | 视觉要点 |
|---|---|---|
| Default | 普通 | 纸面完整、可点 |
| Focus | 焦点 | 轻微抬起/描边（触摸为主，不依赖悬停展示关键信息） |
| Selected | 已选择 | 明确选中反馈 |
| Disabled | 不可操作 | 降饱和 + 禁用原因可见 |
| Resolving | 结算中 | 演出锁，不可重复点击 |
| Removed | 已移除 | 离场动画后释放视图（对象池回收） |
| Warning | 危险提示 | ColorDanger 描边或角标 |

### 点击交互细则（2026-10 冻结）

1. **亮牌两段式**：第一次点击 = Focus（抬起 + ColorPrimary 描边 + Tooltip 展开卡名/效果/数值，敌人卡显示 ATK/HP）；再次点击同一张 = 确认提交（card_selected 入队）；点击其他卡切换选中，点击空白取消——切换与取消均无消耗。
2. **暗牌直接执行**：dark 堆顶牌点击 = 翻开并**立即按效果执行**（风险自负）；剩余张数角标是唯一决策信息，不做预览翻看——保住 R 因子（暗牌占比）的赌性定价。
3. **不做战斗预演**：敌人卡 Tooltip 只显示静态 ATK/HP，不预演伤害交换结果——推演留给自己（连击"先防后攻"取舍的前提）。
4. Disabled 牌：禁用原因牌面可见（驻留封锁等），再点击 Toast 错误码文案（如 CARD_NOT_ACTIONABLE）。
5. 边界：Resolving 结算中点击忽略并提示"结算中"；连点防抖 200ms（§5.1）。

## 4. 统一组件库

| 组件 | 职责 |
|---|---|
| CardView / CardStack | 卡牌展示 / 堆管理 |
| StatusBar / ResourceBadge | 状态总览 / 资源数字图标 |
| ItemButton / PrimaryButton / SecondaryButton | 道具与操作按钮 |
| Modal / Toast | 弹窗 / 轻提示 |
| FloatingNumber | 伤害、治疗、资源飘字（对象池，见 05_Performance.md） |
| Tooltip | 卡牌与道具说明 |
| LevelHeader / ResultPanel | 关卡信息 / 结算 |
| LoadingView / EmptyState | 加载 / 空状态 |

禁止每个页面重写相同功能的按钮、状态栏或卡牌布局。

### 4.1 视图基类与界面层级

**视图基类**（位于 `scripts/ui/`，所有界面与弹窗必须继承，禁止绕过）：

| 基类 | 职责 |
|---|---|
| BaseView | 全屏界面基类：打开/关闭/刷新生命周期；EventBus 订阅随关闭自动注销；只发事件/请求，不改规则 |
| BasePopup | 弹窗基类：底板、遮罩、按钮排布共用；确认/结果/信息三类弹窗只是预设配置（按钮组合、可否点遮罩关闭、优先级）；内置弹窗队列，按优先级排队或合并，禁止多个弹窗直接叠放 |
| Toast | 轻提示：非阻塞、自动消失；能 Toast 的不弹 Modal |

**首批基础弹窗**（BasePopup 预设实例，归统一组件库，禁止在业务模块重复实现）：

| 弹窗 | 用途 |
|---|---|
| MessagePopup | 单按钮信息提示 |
| ConfirmPopup | 双按钮确认/取消 |
| LoadingPopup | 加载/切场景遮罩提示 |
| RewardPopup | 统一奖励展示（数值变化必须可见，见第 5 节） |
| ErrorPopup | 错误码 → 文案映射展示（错误码见 02_Development/10_CodingStandards.md 第 3 节） |

**Canvas 分层节点**（场景内固定层级，从下到上）：

```text
Canvas
├── SceneLayer     场景内容
├── WindowLayer    全屏界面（BaseView 挂载点）
├── PopupLayer     弹窗（BasePopup 挂载点，经队列调度）
├── ToastLayer     轻提示
├── GuideLayer     引导层（输入拦截，见 01_GameDesign/15_Tutorial.md）
└── LoadingLayer   加载遮罩（最上层）
```

规则：

1. 各层职责固定，界面/弹窗只能挂载到对应层，禁止跨层挂载或动态插层。
2. 弹窗必须经 BasePopup 队列显示，结算等高优先级弹窗可打断低优先级提示。
3. 平台系统能力（授权、订阅消息等）不自绘弹窗，走 `services/` 封装的系统弹窗（wx.showModal 等）。
4. 弹窗内文案仍只从 02_CopyDeck.md 取 key。
5. 扩展模式：新增弹窗 = 新建 BasePopup 子类 + 注册到弹窗队列，禁止修改既有弹窗代码（与数据流水线"新增配置不改代码"同一原则，见 02_Development/00_Architecture.md 第 4 节）。
6. **队列优先级（默认，2026-10 拍板）**：只约束**系统自动弹出**的弹窗，数值大者先弹——Error(100) > Reward(80) > Sign(60) > 公告/活动(40)；同优先级按触发先后。**用户主动点击**的弹窗（设置/商店/背包/图鉴/排行榜/我的）即时打开，不入队，可打断系统队列（关闭后队列继续）。
7. 场景切换时队列清空（跨场景不残留弹窗，§1 跳转规则 2）。

## 5. 交互反馈规范

- 点击有效卡牌：明确选中反馈。
- 点击不可操作卡牌：说明原因（对应错误码提示，总规格书 9.8）。
- 使用道具：先展示目标要求，再执行。
- 获得奖励/生命变化：数值变化必须可见。
- 操作失败：给出可理解原因，禁止静默失败。
- 动画不长时间阻塞操作；连续操作由 Resolving 状态 + ActionQueue 防重复结算。

### 5.1 动效时长与输入交互数值（基线）

> 本节数值是编码与测试的判定依据（11_Testing.md 用例 7/8 依赖此表）。标注"基线值"的可在美术/手感调优阶段调整，调整必须同步本表与相关测试用例。

**动效时长上限**（设计分辨率 750×1624 基准）：

| 动效 | 时长上限 | 备注 |
|---|---|---|
| 卡牌选中抬起 | 80ms | Focus 状态反馈 |
| ActionQueue 单条结算动画 | 300ms | 飘字 + 抖动等同批次演出合并计 |
| 死亡演出 | 400ms | 敌人/玩家 |
| 胜利 / 失败演出 | 800ms | 进 LevelResult 前 |
| 卡牌堆掉落入格（战斗开始） | 单堆 300ms、逐堆错峰 60ms、总时长 ≤1s | 准备档口点击战斗按钮后；伴随落地音效与轻微屏震；**掉落期间维持 LevelInit 输入锁（商店/背包不可开），动画结束才进 PlayerTurn；skip 时直接揭示** |
| 弹窗进入 / 退出 | 180ms / 150ms | BasePopup 内置 |
| Toast 存活 | 1500ms | 非阻塞 |
| 飘字存活 | 700ms（上浮 24px） | 对象池回收 |
| 屏幕震动 | 200ms | 受击反馈 |
| BGM 淡入淡出 | 500ms | 见 01_AudioSpec.md §1 |

**输入交互数值**：

| 项 | 基线值 | 说明 |
|---|---|---|
| ActionQueue skip 阈值 | 队列累计演出 > 2500ms | 超限后动画直接呈现终态（0ms），飘字合并为汇总条目（02_Development/03_ActionQueue.md 第 2 节引用此值） |
| 连点防抖 | 200ms | 同一可交互元素两次点击间隔 < 200ms，第二次忽略；卡牌类另由 Resolving 输入锁兜底 |
| 最小热区 | 44 × 44px | 微信惯例；卡牌热区按整卡（方形卡最小渲染 220×220） |
| 滑动判定 | 位移 > 16px 且时长 < 350ms | 判为滑动（堆翻阅），否则判为点击；MVP 仅实现点击 |
| 双击 | 不使用 | 全项目无双击交互，避免与连点防抖冲突 |

## 6. 响应式适配

- 竖屏优先；设计分辨率基准 **750 × 1624**（iPhone X 类安全区基准，含 88px 顶部刘海区预留），宽度固定、高度自适应，缩放策略为 fit width + 安全区内缩（Cocos：Canvas fitWidth + Widget 对齐安全区）。美术启动时冻结。
- 关键按钮不被底部安全区（≥34px）遮挡；卡牌不超出可视区。
- 小屏不依赖过小文字；弹窗内容超出可滚动；堆高随屏幕调整。
- 卡牌单张设计尺寸（2026-10 修订：**统一方形卡**，参考 Card of Darkness 布局弹性）：设计基准 **300 × 300**；渲染按盘面自适应——少堆（≤3）放大至基准，多堆（≥4）单元格缩至 140 × 140；堆叠露边 ≥12px。
- 方形卡排版：卡面只保留 类型图标 / 名称 / 主数值 / 稀有度描边（§3 结构 2/3/5/7），**效果说明移入点按 Tooltip**（Focus 态展开，兼容小屏与多堆小尺寸）。
- 堆布局全阶段统一 **5×5 矩阵盘**（堆数 2～20 按阶段递进，见 06_Levels.md §3.1）；渲染自适应：堆数 ≤3 放大 300×300，≥4 堆单元格 140×140 缩略（仅 icon+数值+角标），空格默认留白（地面纹理），环境装饰稀疏点缀（≤ 空格 1/3）；顶牌可见度按堆配置 lit/dark，同关可混合（"部分亮"）；dark 堆顶牌样式：深色底 + 剩余张数角标。
- 至少在 3 种尺寸设备/模拟尺寸下验证（性能预算与机型假设见 05_Performance.md）。

```text
assets/
├── images/ (cards/ items/ enemies/ backgrounds/ effects/)
```

命名示例：`card_enemy_slime_01.png`、`icon_hp.png`、`bg_dungeon_01.png`、`sfx_card_select.wav`。禁止 `new.png`、`final_final.png` 等无意义命名（AssetValidator 检查）。

## 8. 第三方素材（itch.io）二次加工规范

基础素材取自 itch.io 免费资源包，入库前须过许可证审计（04_Platform/00_Compliance.md 第 4 节）。为达成统一的"暗色故事书"风格，所有外来素材必须完成以下加工才算合格资产：

1. **调色对齐**：像素/手绘素材整体调色至设计变量色板（背景向 ColorBackground、强调向 ColorPrimary 靠拢）；提供统一 LUT/调色参数，全包一致。
2. **重排版**：外来的卡框/按钮/图标按第 3 节卡牌结构与第 4 节组件层级重新组装，不整包原样堆砌。
3. **尺寸归一**：按第 6 节设计分辨率重采样（卡面方形 300×300 基准，多堆缩放档 220×220），大图压缩（03_Packaging.md：单文件 > 100KB 走 CDN）。
4. **风格修补**：不同作者包之间风格冲突处，用统一的装饰线条/边框/描边（第 3 节卡牌结构 1、7）做视觉缝合。
5. **保留记录**：素材包来源、许可证、加工方式记入授权清单（04_Platform/00_Compliance.md 第 4 节），manifest 带 license 字段。

禁止：直接原样混用多个素材包风格而不加工；使用 NonCommercial 许可包（无论加工与否）。

### 8.1 风格基线素材包（2026-10 定稿）

整体 UI 风格基于两个 itch.io 包做二次加工（许可证审计见 04_Platform/00_Compliance.md §4 已审计登记表）：

| 包 | 用途 | 取用内容 |
|---|---|---|
| **gvesster Free Icon Pack** | 全部**图标**（资源/道具/装备槽/状态效果/设置项 icon） | 优先用 **Flat（纯黑白）与 Simple 变体**——最适合重调色到本设计变量色板；64/256px PNG（SVG 需 DEV 版 $4.49，矢量缩放确有需要再购） |
| **RhosGFX Cartoony UI Pack** | **UI 组件**（按钮四态、面板、滑杆、边框） | PNG8 + 分层 SVG 源文件改色；按钮 active/hover/focus/normal 四态齐全，直接映射 PrimaryButton/SecondaryButton |

**风格合成原则**（两包均为卡通/扁平形状语言，与本作"暗色奇幻故事书"的合成方式）：

1. **形状语言照搬，颜色语言重调**：圆角、粗描边、卡通比例、icon 语法直接采用；所有颜色强制映射 §1 设计变量（面板 → ColorPanel，强调 → ColorPrimary，暗底 → ColorBackground），禁止使用素材包原色。
2. **两包混排统一参数**：描边粗细、圆角半径、投影偏移三参数全局冻结一套值，消除两包风格差（§8 风格修补条款）。
3. **黑/白底稿优先**：重调色一律从 Flat/单色稿开始，不上来就用 Recolor 彩色变体（避免色板失控）。
4. **合规红线**（两包均禁止）：素材不得转售/二次打包、**不得输入 AI 图像工具生成衍生图**、不得冒充原创；署名可选但建议在"设置→关于"页致谢并链接作者 itch 页。
5. **预算**：rhosgfx 需购买（$8.99）；gvesster $0 档可用，DEV 版（+$4.49）视矢量需求决定。
