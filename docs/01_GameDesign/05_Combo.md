# 连击系统

> 来源：总规格书 5.1，并为待定项补充默认值。触发与奖励由配置定义。

## 1. 设计目标

连击奖励连续的有效决策，鼓励玩家规划行动序列而不是逐张救火。

## 2. 触发条件

- 连续击败敌人。
- 连续获得资源。
- 连续使用特定类型卡牌（由 tags 配置）。
- 在限定行动次数内完成目标。

## 3. 连击阶段与奖励

| 连击数 | 奖励 |
|---|---|
| 2 | 基础提示（演出反馈） |
| 3 | 少量额外金币 |
| 5 | 额外奖励或资源 |
| 8 | 高阶连击奖励 |

具体奖励数值由 Balance 表配置（见 06_DataBalance.md 第 3 节）。

## 4. 规则默认值（原总规格书待定项，此处冻结）

| 待定项 | 默认规则 | 理由 |
|---|---|---|
| 道具是否触发连击 | **不触发** | 避免道具刷连击；与"连击奖励不触发连击"形成一致闭环 |
| 连击奖励是否再触发连击 | **否** | 防止无限循环（总规格书 5.1 推荐原则） |
| 哪些操作增加连击 | 有效卡牌操作（结算成功且未被 cancelable 取消） | 以 ActionQueue 执行成功为准 |
| 哪些操作中断连击 | 使用道具、受到伤害、死亡 | 伤害中断制造"先防后攻"的取舍（"跳过行动"机制不在 MVP 范围，若后续引入须先补定义） |
| 关卡切换 | **清零** | 连击属于单关即时奖励，不跨关 |

以上默认值如需调整，按数值变更流程记录（总规格书 14.3）。

## 5. 实现要求

- 连击计数存于 `GameState.combo`（见 01_GameState.md），由连击系统在 ActionQueue 的 priority 60 阶段结算（03_ActionQueue.md 第 4 节）。
- 连击更新发布 `combo_updated` 事件（04_EventCatalog.md），UI、音效为普通监听者。
- 奖励发放构造新 Action 入队，不直接改资源。
- 边界测试覆盖：连击 2/3/5/8 恰好触发、伤害中断、道具不计数、跨关清零（总规格书 12.2-18 连击无限循环用例）。
