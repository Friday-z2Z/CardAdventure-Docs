# 战斗系统详设

> 补全章节。此前战斗规则散在 03_Cards.md A 节，本文补齐战斗的完整生命周期：驻留规则、Turn、状态加成进公式、反击与烟雾弹。数值基线见 09_BalanceBaseline.md。

## 1. 战斗生命周期

1. **开战**：玩家选中敌人卡（ActionResolver 校验通过）→ 该敌人成为**当前敌人**。
2. **每次行动**：走一次 ActionQueue 结算批次（03_ActionQueue.md 第 4 节）。
3. **结算后判定**：敌人 HP ≤ 0 → 死亡发放奖励，敌人卡移除；HP > 0 → 进入**驻留**（见第 2 节）。
4. **战斗结束**：当前敌人死亡或玩家死亡，无第三种结束方式。

## 2. 驻留与封锁规则（原型冻结，需实测）

- 敌人未死亡时，**敌人卡驻留在原堆顶层，封锁该侧卡牌堆**：该侧后续卡牌不可操作（Disabled 状态，注明"先解决敌人"）。
- 另一侧卡牌堆不受影响，可自由操作。
- 驻留敌人**不主动反击**：反击只在玩家攻击它的行动中发生（priority 40）。
- 封锁产生的压力是策略来源：想拿被封锁侧后面的卡，必须先清掉敌人或用道具。

> 备选方案（若实测压力过大）：驻留敌人改为"每次玩家行动结束时反击一次"。调整须走 09_BalanceBaseline 第 7 节流程。此规则只影响阶段一～二；阶段三起的"多敌同场"由关卡配置 spawnCard 实现，届时"当前敌人"取堆顶层第一个存活者。

## 3. Turn（行动次数）定义

- **何时 +1**：每次玩家有效行动结算完成后（ActionQueue priority 60 之前）+1。
- **驱动什么**：状态效果的 `duration` 递减单位；连击时限判定；后续限时触发条件的配置基准。
- 不跨关卡，随 GameState 重建归零。

## 4. 状态加成进公式（完整伤害公式）

```text
玩家有效攻击 = max(1, 玩家攻击力(含装备) + 技能加成 - 玩家weakness减攻)
玩家对敌人伤害 = max(1, 玩家有效攻击 - 敌人防御力) × (vulnerable ? 1.5 : 1)

敌人有效攻击 = 敌人攻击力 + 敌人技能加成
敌人对玩家伤害 = max(0, 敌人有效攻击 - 玩家防御力(含装备))
```

敌方伤害落地顺序（固定，与护盾类道具共用同一路径）：

```text
1. 算出敌人对玩家伤害 D
2. Shield 抵消：absorbed = min(Shield, D)；Shield -= absorbed
3. 剩余 remain = D - absorbed 直接扣 HP
```

顺序恒为：**先算减免、再抵护盾、最后扣血**。

## 5. 反击与烟雾弹

- 反击是 priority 40 的标准动作，仅当行动结束时当前敌人仍存活才执行。
- `smoke_bomb` 的实现：给当前敌人挂 `skip_counter: 1` 标记，反击效果 `condition` 检查该标记，命中则跳过并清除标记。
- 反击可被 `cancelable` 链取消的只有免疫类效果；烟雾弹走条件跳过，不走 cancelable（两者不叠加）。

## 6. 与其他系统的边界

| 事项 | 归属 |
|---|---|
| 敌人数值、特殊效果配置 | EnemyValidator / 敌人配置（06_DataBalance.md） |
| 中毒/灼烧等 tick | 状态系统在 priority 50 结算（02_Player.md） |
| 击杀奖励 | 奖励系统监听 `enemy_died`（12_Rewards.md） |
| 驻留封锁的 UI 表现 | CardStack Disabled 状态（03_UI/00_UiSpec.md 卡牌状态表） |
