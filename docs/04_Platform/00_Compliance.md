# 合规与上架

> 上线硬门槛。微信小游戏不满足本清单无法过审或无法上线。以微信官方当期要求为准，本文列出开发侧必须预留的工作项。

## 1. 上线前置清单

| 项 | 要求 | 开发侧动作 |
|---|---|---|
| 主体资质 | **游戏类目不接受个人主体** | 个人开发者注册**个体工商户或企业主体**后再创建小游戏；本项目为个人开发，主体注册是第一优先事项 |
| ICP 备案 | 小游戏须完成备案（2023-09 起新规） | 主体注册后提交，预留 1～4 周 |
| 软著 | 类目审核通常要求计算机软件著作权 | 个体户/企业名义申请，立项后即启动（周期 1～3 个月，可加急） |
| 版号 | **仅内购（虚拟支付）需要**；纯广告变现暂不需要 | 本项目为个人开发，内购线已冻结（01_Monetization.md 第 1 节），版号不阻塞上线 |
| 用户隐私保护指引 | 后台填写收集哪些用户数据及用途 | 与第 2 节对齐，只声明实际收集项 |
| 内容自查 | 无违规内容、素材版权干净 | **itch.io 素材逐包许可证审计**（第 4 节）+ 字体/音频授权归档（12_Delivery_Risk.md 第 1 节 D） |

## 2. 隐私合规（开发侧必须做）

1. **最小收集**：本项目单机优先，正常游玩不收集任何用户信息；仅排行榜（02_Leaderboard.md）经开放数据域/云开发涉及昵称与头像。
2. **隐私弹窗**：首次进入排行榜/分享功能前触发 `wx.requirePrivacyAuthorize` 授权流程；拒绝授权时降级为"不显示排行榜"，不阻断主流程。
3. **隐私接口声明**：后台声明用到的隐私接口（getUserProfile 等），未声明接口调用会被拦截。
4. **不收集**：身份证、手机号、位置、相册。健康实名由微信平台侧处理，开发侧不做也不接触。

## 3. 未成年人保护

- 实名与未成年人时长限制由微信平台统一执行，开发侧无需自建健康系统。
- 开发侧义务：不设计诱导未成年人消费的机制（内购确认弹窗不可跳过）；广告内容合规由微信广告侧过滤。

## 4. 第三方素材（itch.io）使用规范

UI 素材来自 itch.io 免费资源（https://itch.io/game-assets/free）。免费 ≠ 可随意商用，**每个素材包入库前必须过一遍许可证审计**：

| 许可证类型 | 能否用于本项目 | 动作 |
|---|---|---|
| CC0 / Public Domain | ✅ 可 | 记录来源即可 |
| CC-BY（署名） | ✅ 可 | 设置页"关于"加入署名名单 |
| 明示 Commercial Use Allowed | ✅ 可 | 同上，按包要求处理署名 |
| NonCommercial / 仅限个人学习 | ❌ **禁用** | 本项目有广告变现 = 商业使用，直接排除 |
| 许可证不明 / 无 LICENSE 文件 | ❌ 禁用 | 找不到明确授权就不用 |

硬性规则：

1. **入库登记**：每个素材包记录到授权清单（包名、作者、itch 链接、许可证类型、下载日期、截存的许可页凭证）；清单随交付物归档（12_Delivery_Risk.md 第 1 节 D），构建期 `check:licenses` 脚本核对 manifest 引用的每个资源都有已审计的来源（03_Packaging.md 第 2 节 manifest 增加 license 字段）。

共同约束（两包均声明 No generative AI was used，且禁止素材进 AI 训练）：**严禁将素材输入任何 AI 图像工具生成衍生图**，二次加工仅限人工调色/重排（00_UiSpec.md §8）。两包署名均非强制，但建议在设置→关于页做素材致谢（链接作者 itch 页）。
2. **不二次分发**：禁止把 itch 原始素材包重新打包上传到任何地方；只允许作为游戏运行资源内嵌。
3. **署名页**：设置 → 关于 → "素材与致谢"，列全部需署名包（CopyDeck 第 5 节登记）。
4. **二次加工**：允许改色/缩放/重排版以统一视觉（00_UiSpec 第 8 节），但不得移除作者嵌入的署名水印类元素。

## 5. 内容红线

- 美术与文案不做恐怖血腥渲染（ColorDanger 用色即可，不做血腥表现）。
- 引导与文案遵守 CopyDeck 语气基准，不出现诱导分享的强制话术（05_Share.md 第 4 节）。
