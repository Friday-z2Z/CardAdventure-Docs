# 测试方案

> 来源：总规格书第十二章。五层测试 + 边界用例 + 自动化 + 质量门槛。

## 1. 五层测试

| 层 | 范围 | 重点 |
|---|---|---|
| 一：单元 | 独立规则 | 伤害公式、防御护盾、生命恢复、食物扣除、金币变化、道具数量、状态持续时间、连击条件、出口判定、存档序列化 |
| 二：集成 | 多系统协作 | 炸弹击杀领奖、中毒行动后结算、护盾抵消、道具扣库存、机关开出口、结算发奖、存档恢复续玩 |
| 三：关卡 | 全部正式关卡 | 配置/生成/出口/资源/道具合法性、种子复现、自动模拟、固定关人工通关 |
| 四：UI 与设备 | 真机表现 | 屏幕尺寸、安全区、触摸响应、快速连点、动画期操作锁、弹窗返回、切后台恢复、低性能设备、资源加载失败 |
| 五：发布验收 | 上线前 | 启动、首次流程、存档读取、关卡切换、失败重试、通关下一关、重进、长时间运行、异常恢复、包完整性 |

## 2. 必须覆盖的 20 个边界情况

1. HP 恰好归零；2. 护盾恰好抵消全部伤害；3. 恢复超上限；4. Food 归零；5. Gold 不足以支付；6. 道具数量恰好归零；7. 重复点击同一张卡；8. 动画期间再点击；9. 玩家与敌人同时死亡；10. 出口不存在；11. 关卡目标无法满足；12. 随机种子无效；13. 存档字段缺失；14. 存档版本过旧；15. 资源加载失败；16. 结算过程中退出；17. 恢复后重复发奖；18. 连击奖励无限循环；19. 状态重复叠加；20. 生成出重复/非法卡牌。

## 3. 自动化

每次代码修改后运行：类型检查、单元测试、核心集成测试、全部关卡配置检查、随机种子复现测试。500 关必须支持批量检查，禁止逐关手点（CI 跑 Validator + 模拟，见 06_DataBalance.md）。

## 4. 质量门槛（发布候选）

- 核心规则单元测试、核心集成测试全部通过。
- 500 关配置全部通过静态验证。
- 固定关卡均有通关验证记录（格式见 06_Levels.md 第 5 节）。
- 关键路径无已知阻断问题；无数据重复发放漏洞；无不可恢复存档损坏；无严重崩溃。
- 主要设备尺寸适配通过；性能达预算（05_Performance.md）。

**不能仅以"游戏能启动"作为交付标准。**

## 5. 2026-10 系统修订新增用例（对应各文档修订，开工时并入第一/二层）

**难度与关卡（第一/三层，来源 06_Levels.md §3.1～3.1.2）**

- DIFF 四因子计算边界（0 堆 / 全暗 / 深度饱和）；等价交换两套四维配置落同带
- 教学关 DIFF ≤15 拦截；首领关 +10 上浮
- matrix5 校验：占格重叠 / 坐标越界 / 堆数超限（>20）打回
- depth 三档制：浅堆占比 <40% 打回；梯度 max ≥ min×1.5 且差 ≥3 不达标打回
- 种子复现回归：cell/depth/reveal 为静态配置，同种子堆序列与奖励逐张一致

**经济系统（第一/二层，来源 11_Resources.md §3、16_Shop.md、17_SignIn.md）**

- 金币双层制：胜利转钱包幂等（重复结算不重复转存）；失败没收；进关不携带钱包金币
- 商店：钱包不足回 NOT_ENOUGH_GOLD 且不产生负数；每日免费刷新自然日重置
- 签到：自然日判定、同日重复拦截、第 7 日归位、奖励发放幂等

**局内交互（第二/四层，来源 03_UI/00_UiSpec.md 点击交互细则、03_Screens.md 2.1）**

- 卡牌两段式：选中/切换/取消/确认状态流转；暗牌点击直接执行且消耗与亮牌一致
- Disabled 点击报 CARD_NOT_ACTIONABLE；Resolving 中点击忽略并提示"结算中"
- 连点防抖 200ms；队列演出 >2500ms 触发 skip
- 系统入口：Resolving 中打开排队至队列清空；保存退出 → 断点写入 → 主界面"继续冒险"恢复一致
- 音乐/音效/震动开关即时生效并持久化
- 弹窗队列：高优先级打断与合并（BasePopup）

**存档与状态机（第二层，来源 02_StateMachine.md 规则 9/10、12_Rewards.md §3、10_CodingStandards.md §4.1）**

- 重开本关：丢弃断点、固定关原种子 / 随机关新种子
- 幂等集合 rewardedKeys 随快照持久化——恢复后重复发奖被拦截（用例 17 的实现验证）
- 存档迁移 fixtures（tests/fixtures/saves/，walletGold / signData / 局内手动退出兼容）
- 局内手动退出与杀进程自动断点两条路径落盘内容一致
