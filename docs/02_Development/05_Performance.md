# 资源生命周期与性能预算

> 新增章节（采纳评审建议八、九），并具体化总规格书第十三章。微信小游戏内存受限，本文数字为硬预算，超出需在代码审查中说明。

## 1. 性能预算（冻结项）

| 指标 | 预算 | 说明 |
|---|---|---|
| 主包体积 | ≤ 4MB | 微信硬限制，超限走分包/CDN |
| 首次启动（可交互） | ≤ 5s | 中端安卓机 |
| 首次进入关卡 | ≤ 1.5s | 含布局生成 |
| 关卡切换 | ≤ 1s | 读取 + LevelInit |
| FPS | ≥ 50 | 中端机目标 60 |
| 同屏 DrawCall | ≤ 60 | 卡牌 + 飘字场景 |
| 纹理内存 | ≤ 40MB | 常驻 + 当前关卡 |
| 音频内存 | ≤ 8MB | BGM 循环复用 |
| 峰值 JS 堆 | ≤ 256MB | 含引擎，长时间运行不增长 |

预算随最终引擎与机型基线在"阶段 1 技术验证"时冻结（总规格书 13.3），冻结后修改需评审。

## 2. 资源生命周期

所有资源经 `IAssetService` 加载（总规格书 13.2），按场景划分持有域：

| 阶段 | 加载 | 释放 |
|---|---|---|
| Boot / Loading | 核心资源：字体、图标、主界面 UI、存档 | — |
| MainMenu | 主界面背景、按钮音效 | — |
| LevelInit | 当前关卡卡牌图、敌人图、BGM | 上一关专属资源 |
| Resolving / PlayerTurn | 增量（新卡图、特效图） | 离开卡牌堆不再引用的图 |
| LevelResult | 结算面板资源 | — |
| 返回 MainMenu | 常驻资源 | 全部关卡资源、战斗 BGM |

规则：

1. 只加载当前需要的资源（总规格书 13.1）；进入关卡才拉取该关卡图集。
2. 场景退出必须显式释放非常驻资源；持有域外的引用视为泄漏，审查时核查。
3. 资源加载失败显示回退占位内容，不允许白块或崩溃（总规格书 13.2）。
4. 500 关配置数据走分包 + 按需加载（每阶段一个分包），本地缓存已下载分包。

## 3. 对象池

以下对象**禁止直接 new / 销毁**，必须走对象池：

| 对象 | 池策略 |
|---|---|
| FloatingNumber 飘字 | 常驻池，上限 20，超出丢弃最旧 |
| 卡牌视图 CardView | 每卡牌类型缓存 1 个模板实例，复用换数据 |
| 命中/恢复特效 | 池上限 10 |
| 事件面板 Modal | 复用单例，切内容不复建 |

实现要求：池化对象必须完整 reset（透明度、层级、事件监听），回收时移除 EventBus 监听。
